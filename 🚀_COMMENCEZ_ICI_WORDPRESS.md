## ⚡ Démarrage Ultra-Rapide (Si vous êtes pressé)

```
1. Téléchargez Local: https://localwp.com/
2. Installez et créez un site "munisys-site"
3. Installez Breakdance dans WordPress
4. Lancez: node export-to-wordpress.js
5. Éditez les pages avec Breakdance
✅ Terminé!
```
